# Quotes Scraper

A lightweight Python script designed to scrape quotes, authors, and tags from [Quotes to Scrape](https://quotes.toscrape.com/) and export the structured dataset into a CSV file.

## Tech Stack
* **Python**
* **Requests** (HTTP requests)
* **BeautifulSoup4** (HTML parsing)
* **Pandas** (Data manipulation & CSV export)

## Features
* Extracts quote text, authors, and associated tags safely.
* Organizes multiple tags into clean, structured strings.
* Automatically saves extracted data to `quotes_data.csv`.
